# Q3/FY 下一年盈利预测能力提升计划

## 1. 目标与范围

目标：在不破坏现有 Q1/H1 稳定性的前提下，提升 Q3/FY 对下一年盈利方向与幅度的预测能力。

核心指标（只看 Q3/FY）：

- 分类：`cls_auc`、`cls_acc`
- 回归：`reg_mae`
- 稳定性：滚动年份评估方差（按年度切片）

约束：

- 先做最小侵入改造，优先可回滚。
- 单次改动尽量只改变一个变量，避免归因混淆。

## 2. 问题分解

Q3/FY 的 t+1 任务难度明显高于 t 任务，主要来自：

- 标签噪声更大：跨年后经营与口径变化更多。
- 时间漂移更强：老年份样本对当前市场结构解释力降低。
- 行业异质性更高：同一模型在行业间表现差异大。

## 3. 路线图（按优先级）

### Phase 1（立即落地，低风险）

1. 时间衰减样本权重（Time Decay）
- 目的：降低老年份样本对 Q3/FY t+1 任务的干扰。
- 方式：按年份构建指数衰减权重，最近样本权重更高。
- 策略：仅对 `Q3/FY` 启用，默认关闭，配置开关控制。

2. 训练指标补充
- 在 metrics 中记录是否启用权重、权重参数、权重范围，便于审计和回归分析。

### Phase 2（下一步）

1. 标签质量降权（Label Quality Weight）
- 目的：对疑似噪声标签降权，而非直接丢弃。
- 候选特征：是否存在重述、口径跳变、极端一次性损益代理变量。

2. 行业后校准（Post Calibration）
- 分类概率做行业级校准（温度缩放或 isotonic）。
- 回归结果做行业偏置修正（残差均值/分位数修正）。

### Phase 3（结构升级）

1. Q3/FY 共享骨干 + 专门头（多任务）
2. 滚动窗口验证与模型选择自动化

## 4. 实验矩阵（建议）

固定数据版本与切分后，做以下对照：

1. Baseline（当前）
2. Baseline + Time Decay
3. Baseline + Label Quality Weight
4. Baseline + Time Decay + Label Quality Weight
5. Baseline + Time Decay + Label Quality Weight + 行业后校准

统一比较口径：

- Q3: `cls_auc` / `reg_mae`
- FY: `cls_auc` / `reg_mae`
- 以及行业尾部（最差 20% 行业）是否改善

## 5. 验收标准

满足以下任一组合即可视为有效提升：

1. Q3 与 FY 的 `cls_auc` 同时提升，且 `reg_mae` 不恶化超过 1%。
2. Q3 或 FY 的 `cls_auc` 明显提升（>= 0.01），另一个保持基本稳定（绝对变化 < 0.005）。
3. 行业尾部表现改善明显，且总体指标不退化。

## 6. 回滚与风险控制

- 所有增强项通过配置开关控制，默认可关闭。
- 每次训练写入完整参数与开关状态到 metrics。
- 若出现退化，直接关闭增强项并复用上一版 model_version。
