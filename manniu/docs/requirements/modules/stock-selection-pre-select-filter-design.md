# 慢牛牛（MooNiuNiu）选股系统指标体系 V1.0

## 设计原则

所有预设筛选器统一基于以下五大维度构建：

1. 成长性（Growth）
2. 盈利质量（Profitability）
3. 现金流质量（Cash Flow）
4. 财务健康（Financial Health）
5. 估值水平（Valuation）

系统所有预设筛选器均通过这五大维度组合形成，仅调整不同维度的筛选条件。

---

# 一、成长性（Growth）

衡量企业未来成长潜力。

| 指标 | 默认范围 |
|--------|--------|
| 营收增长率 | 0%~50% |
| 净利润增长率 | 0%~50% |
| EBIT增长率 | 0%~50% |

---

# 二、盈利质量（Profitability）

衡量企业赚钱能力。

| 指标 | 默认范围 |
|--------|--------|
| ROE | 0%~30% |
| ROIC | 0%~30% |
| 毛利率 | 0%~80% |
| 毛利率同比改善 | 是/否 |

---

# 三、现金流质量（Cash Flow）

衡量利润真实性。

| 指标 | 类型 |
|--------|--------|
| 经营现金流为正 | 开关 |
| 自由现金流为正 | 开关 |
| 净现金企业 | 开关 |
| 现金利润比 | 数值 |

---

# 四、财务健康（Financial Health）

衡量企业抗风险能力。

| 指标 | 默认范围 |
|--------|--------|
| 资产负债率 | 0%~100% |
| 流动比率 | 0~5 |
| 商誉占净资产比例 | 0%~100% |

---

# 五、估值水平（Valuation）

衡量是否值得买入。

| 指标 | 默认范围 |
|--------|--------|
| PE(TTM) | 0~100 |
| PB | 0~10 |
| PEG | 0~5 |
| 股息率 | 0%~10% |

---
