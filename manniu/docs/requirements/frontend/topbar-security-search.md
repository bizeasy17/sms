# TopBar 证券搜索需求

## 1. 目标

在研究首页 TopBar 提供全局证券搜索，支持按股票名称、交易代码或中文拼音检索证券，并快速切换到对应的研究页面。

## 2. 使用场景

- 用户点击搜索框或按 `Ctrl+K` 聚焦搜索框。
- 用户输入股票名称、完整/部分交易代码或中文全拼、拼音首字母。
- 系统调用 `GET /api/v1/market-analysis/securities` 获取匹配证券。
- 下拉列表按一行一条展示：股票名称、交易代码、行业、上市日期。
- 用户通过鼠标点击或键盘 `↑`、`↓`、`Enter` 选择证券，页面切换到该证券研究视图。
- 用户按 `Escape` 关闭下拉列表并保留已输入内容。

## 3. 接口合同

请求：

```text
GET /api/v1/market-analysis/securities?q={keyword}&asset_type=STOCK&page=1&page_size=8
```

响应使用统一包装，证券项至少包含：

- `name`: 股票名称
- `ts_code`: 标准交易代码
- `industry`: 行业名称，可为空
- `list_date`: 上市日期，可为空

搜索请求应携带当前登录用户的访问令牌，并支持通过 `AbortController` 取消过期请求。

## 4. 交互与状态

- 输入为空时不请求接口，下拉列表关闭。
- 输入变化后延迟约 220ms 请求，避免每个按键立即发送请求。
- 请求期间显示加载状态；无匹配时显示明确的空结果状态；请求失败时显示可重试的错误提示。
- 当前高亮项使用 `aria-activedescendant` 标识；输入框使用 `role="combobox"`，下拉列表使用 `role="listbox"`。
- `Ctrl+K` 和 macOS `Meta+K` 都应聚焦并选中输入内容。
- 选择证券后关闭下拉列表，更新 URL 中的 `ts_code`，复用研究页已有数据加载流程。

## 5. 验收标准

1. 桌面端按 `Ctrl+K` 可以聚焦搜索框。
2. 名称、代码、拼音查询均能将关键词传给上述接口并展示结果。
3. 每条结果在单独一行显示名称、代码、行业和上市时间。
4. 鼠标点击、`Enter` 均能进入所选证券研究页；键盘上下键能切换高亮项。
5. 过期搜索请求不会覆盖最新输入结果，构建和现有前端测试通过。
