# OpenClaw 股票名称容错解析 PRD

## 1. 背景

当前问答入口 `POST /api/openclaw/valuation/chat/` 以 `ts_code` 为核心入参。
虽然已支持从 `message` 中提取 `600519.SH` 这类代码，但对用户常见输入形态支持不足：

- 只输入股票简称（如“招行”）
- 输入非全称（如“招商”）
- 发音接近但有错字（如“赵商银行”）

目标是在不改动估值内核的前提下，补齐“自然语言到标的代码”的解析层。

## 2. 目标与非目标

### 2.1 目标

- 在 `ts_code` 缺失时，支持根据 `message` 自动解析股票。
- 对模糊输入返回可解释的候选列表，要求用户二次确认。
- 兼容现有 API 契约，保持已有 `ts_code` 直通路径不变。

### 2.2 非目标

- 不在本期引入用户级别的个性化别名学习。
- 不在本期引入向量检索或外部搜索服务。
- 不修改估值方法、权重、阈值等金融逻辑。

## 3. 术语

- 解析成功（resolved）：可直接得到唯一 `ts_code`。
- 待澄清（ambiguous）：有多个高相关候选，需用户选择。
- 解析失败（not_found）：无法得到可信候选。

## 4. 用户场景

1. 用户输入“帮我看下招商银行估值”
   - 系统解析为 `600036.SH`，直接返回估值建议。

2. 用户输入“帮我看下中联”
   - 系统返回候选列表（例如中联重科等），提示用户选择。

3. 用户输入“赵商银行现在能买么”
   - 系统通过字符串相似度召回“招商银行”，若置信度不足则返回候选确认。

## 5. 方案设计

### 5.1 总体流程

1. 若请求中显式传 `ts_code`，直接使用。
2. 否则先尝试从 `message` 提取标准代码（现有逻辑）。
3. 仍未命中时，执行名称容错解析：
   - 从文本提取名称线索（去除“估值/怎么样/能买吗”等干扰词）
   - 以 `Corporation` 的 `name/fullname/cnspell` 做召回
   - 基于相似度规则排序
4. 根据分数阈值分流：
   - Top1 >= 0.90：自动采用
   - 0.70 <= Top1 < 0.90：返回候选列表请求确认
   - Top1 < 0.70：返回未识别提示

### 5.2 数据来源

- `valuation_corporation`（Django 模型 `Corporation`）
  - `ts_code`
  - `name`
  - `fullname`
  - `cnspell`

### 5.3 打分规则（MVP）

对每个候选计算综合分：

- 名称相似度（`difflib.SequenceMatcher`）：基础分
- 精确命中 `name/fullname`：+0.25
- 前缀命中：+0.10
- 包含命中：+0.05
- 拼音字段前缀命中（英文字母输入）：+0.20

最终分数限制在 `[0, 1]`。

### 5.4 返回约定

当待澄清时，`openclaw_valuation_chat` 返回：

- `need_clarification: true`
- `answer`: 提示文本
- `symbol_resolution`: 结构化候选信息
  - `status: ambiguous`
  - `query`
  - `candidates[]`（`ts_code/name/fullname/score`）

## 6. 接口兼容性

- 不移除任何现有字段。
- 成功场景下，沿用当前输出：`skill/answer/valuation/...`。
- 仅在 `ts_code` 无法直接确定时新增 `symbol_resolution` 相关字段。

## 7. 风险与缓解

- 风险：短词（如“平安”）歧义高。
  - 缓解：阈值分流 + 候选确认，不自动误匹配。

- 风险：实时数据库搜索性能。
  - 缓解：限制候选查询数量（如 30），并只在 `ts_code` 缺失时触发。

- 风险：错字过多导致召回不足。
  - 缓解：返回明确补充提示（请提供交易所后缀或更完整名称）。

## 8. 验收标准

1. 输入“招商银行估值”可直接命中 `600036.SH`。
2. 输入“赵商银行估值”返回候选且包含“招商银行”。
3. 输入明显无关词汇时，返回“未识别标的”提示，不触发估值计算。
4. 已传 `ts_code` 的请求行为与改造前一致。

## 9. 迭代计划

- P0（本次）：规则检索 + 候选澄清。
- P1：引入别名表（简称、历史名称、用户高频错写）。
- P2：引入拼音库与纠错词典，提升同音错字召回。
