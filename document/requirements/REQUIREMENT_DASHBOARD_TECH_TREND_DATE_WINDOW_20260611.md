# REQUIREMENT_DASHBOARD_TECH_TREND_DATE_WINDOW_20260611

## 背景
- 当前 Dashboard 技术趋势区中，`1y` 选项实际传参为 `count=200`（交易日根数），导致展示区间通常只有约 10 个月。
- 业务预期为按自然日期窗口截取，例如在 2026-06-11 观察时，展示 2025-06-11 至 2026-06-10 的日线范围。

## 目标
- 将技术趋势 K 线展示从“按根数”切换为“按日期窗口”截取。
- 对用户可见的 `1y/2y` 等周期含义，统一为自然日期窗口，而非固定 bars 数。
- 新增 `5Y`、`10Y` 周期选项，并按自然日期窗口展示。

## 归属服务确认
- 建议实现服务：`smartinvestor_fe`（前端展示与筛选逻辑）。
- 后端 `trading-history` 接口可暂不改动，继续返回足够长历史后由前端按日期窗口裁剪。

## 方案（最小改动）
1. 前端在 `StockChart` 侧新增“周期 => 日期窗口”裁剪逻辑。
2. `fetchTradingHistory` 请求上调为足够覆盖窗口（例如 D 线至少 520 bars），避免 2y 视图数据不足。
3. 裁剪规则：
   - 以最新交易日为锚点。
   - `1y`：起点 = 锚点往前 1 年（含）。
   - `2y`：起点 = 锚点往前 2 年（含）。
   - `5y`：起点 = 锚点往前 5 年（含）。
   - `10y`：起点 = 锚点往前 10 年（含）。
   - `30/60` 保持近交易日 bars 语义（如需可后续统一为日期窗口）。
4. 保证与现有指标（MA/TP/SL/量能）联动一致，裁剪后各序列长度对齐。

## 验收标准
- 选择 `D + 1y` 时，横轴起止约等于最近自然一年。
- 选择 `D + 2y` 时，横轴起止约等于最近自然两年。
- 选择 `D + 5Y/10Y` 时，横轴起止约等于最近 5/10 年。
- 图表渲染无错位、无空白断裂，缩放与悬停联动正常。

## 风险与回退
- 风险：若请求 bars 不足，日期窗口会自动退化为可得范围。
- 回退：保留原始 bars 模式实现，可快速切回。
